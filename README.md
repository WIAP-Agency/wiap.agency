# WIAP

Design. Build. Scale.

WIAP (Web Innovation & Application Projects) is a digital agency focused on creating meaningful experiences through design, engineering and technology.

## Tech Stack

- React
- Vite
- Tailwind CSS v4
- GSAP
- ScrollTrigger
- Lenis
- Lucide React

## Features

### Hero Experience

An immersive introduction communicating WIAP's value proposition.

### What We Do

GSAP-powered stack cards revealing service offerings.

### Why WIAP

Interactive accordion highlighting WIAP's philosophy and approach.

### Capabilities

Cursor-follow project previews showcasing selected work.

### Process

Scroll-driven storytelling illustrating WIAP's four-step methodology:

- Discover
- Design
- Build
- Scale

### Technologies

A showcase of the tools and technologies used to build modern digital experiences.

### Consultation Form

Lead generation experience integrated directly into the website.
